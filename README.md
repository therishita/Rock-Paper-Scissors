# Rock Paper Scissors

A simple **Rock Paper Scissors** game built using Python.

## Features

* Player vs Computer gameplay
* Random computer choices
* Displays the result of each round
* Simple terminal-based interface

## How to Run

Make sure Python is installed, then run:

```bash
python rockpaperscissor.py
```

## Tech Used

* Python
* `random` module

## How It Works

The player chooses **Rock, Paper, or Scissors**, while the computer makes a random choice. The program then compares both choices and determines the winner.
